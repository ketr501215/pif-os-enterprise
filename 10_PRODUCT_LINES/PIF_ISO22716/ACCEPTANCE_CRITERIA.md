# Acceptance Criteria - PIF + ISO22716 Product Line

Date: 2026-06-25

A product-line release is not ready until:

1. Knowledge base sources are traceable.
2. Ingredient/toxicology records have source and version fields.
3. Generated documents have repeatable inputs and output hashes.
4. ISO22716 checklist evidence is linked to the relevant document pack.
5. Release gate emits PASS/HOLD with exact blockers.
6. Client data is kept outside public/shared backup paths.
